GENERAL M907 SUMMING/OUTPUT MODULE The M907 is designed to receive up to five separate mixed feeds from the mixing busses of the Renaissance series of radio consoles. The signals are independently processed and amplified to standard user configurable line levels. The outputs of the M907 supply the main program output channels of the console system and provide bridging feeds for the monitoring section and metering sections of the console. OPERATIONAL DESCRIPTION M907 SUMMING/OUTPUT MODULE Refer to drawing A 907-04-002 1) A1 Level Adjust The A1 level adjust trim control allows setup of the console output level to standard operating levels for the A1 amplifier chain. This could be one of three busses from the console system: AUX 2 left, PGM 1 music left, or PGM 3 left. 2) A2 Level Adjust The A2 level adjust trim control allows setup of the console output level to standard operating levels for the A2 amplifier chain. This could be one of three busses from the console system: AUX 2 right, PGM 1 music right, or PGM 3 right. 3) A1+A2 Level Adjust The A1+A2 level adjust trim control allows setup of the console output level for the sum of A1 and A2 outputs. This provides a mono sum output. 4) A3 Level Adjust The A3 level adjust trim control allows setup of the console output level to standard operating levels for the A3 amplifier chain. This could be one of three busses from the console system: PGM 1 voice left, PGM 2 left, and PGM 4 left. 5) A4 Level Adjust The A4 level adjust trim control allows setup of the console output level to standard operating levels for the A4 amplifier chain. This could be one of three busses from the console system: PGM 1 voice right, PGM 2 right, and PGM 4 right. 6) A3+A4 Level Adjust The A3+A4 level adjust trim control allows setup of the console output level for the sum of A3 and A4 outputs. This provides a mono sum output. 7) A5 Level Adjust The A5 level adjust trim control allows setup of the console output level to standard operating levels for the mono A5 amplifier chain. This could be one of two busses from the console system; AUX 1 or MIX MINUS. All channels operate ina similar fashion, so the following description refers to channel A1 only. Input The signal originating from the external mixing network enters the module at connector P1 pin 2. The signal is routed through user programmable jumper LK5 and into the summing node of U1. U2, along with capacitors C21, C22, C152, C153 and resistors R18, R19, R20, R21, and R22 form a 30 kHz low pass filter with a -40 dB per decade roll off characteristic. The output of U2 provides a nominal level of -6 dBu at connector P2 pin 1. Insert An unbalanced insert point is provided between connector P2 pin 1 and P2 pin 2. This permits the insertion of an external equalizer, limiter or compressor into the main program channel. Level Adjustment From the insert point, the signal is returned to the module and is coupled to level adjust potentiometer R24. When the console is operated at operating levels of 0 dBu or +4 dBu, LK23 is shorted; for operation at +8 dBu, LK23 is opened. Trimming the output level is done by adjusting R24 which is front panel accessible. Output Output of the module is balanced through amplifiers U3 and U4. A 60 ohm output network provides two external stereo outputs for the console and a metering output for use by the console meter module (M909) and the monitor module (M905). M907 channels A1 &amp; A2 (and A3 &amp; A4) are combined to provide a mono sum output through U9 and U10. A single mono output is available for external use from the console system. Power Supply The power supply is decoupled through a passive decoupling circuit consisting of R1, R8, R153, R154 and C1, C6, C142, C143 for channel 1. Nominal power supply voltage at the amplifiers is 22 volts. Configurations The M907 is designed to be a universal output amplifier for the Renaissance series of consoles. to this end, it is possible to assign a summing bus to a particular output channel with certain restrictions.
